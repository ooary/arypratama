I've been tinkering with AI assistants for a while now. Most of them are either locked behind subscriptions, force you to use their apps, or just feel... corporate. Then I found **ZeroClaw**, and it's been a game-changer.

## So, What Is ZeroClaw?

ZeroClaw is an **open-source AI assistant** written in Rust. Think of it as your own personal AI that you control completely. It's fast (the binary is only ~3MB!), runs locally or on your server, and doesn't phone home to anyone unless you want it to.

Here's what makes it special:

- **Multi-channel** — Works on Telegram, WhatsApp, Slack, Discord, Matrix, email, SMS, even web chat
- **Multi-provider** — Use OpenAI, Claude, Gemini, DeepSeek, or run local models via Ollama/llama.cpp
- **Built-in tools** — File system, shell commands, web browser, memory, scheduling, HTTP requests
- **Extensible** — Write custom tools in Python or Rust
- **Memory** — Actually remembers things across conversations (stored locally)

## Memory That Actually Works

This is my favorite part. Most AI assistants have **no memory** — you start fresh every conversation. Or they have "memory" that's just a hacky workaround.

ZeroClaw has **real, persistent memory**:

- **Long-term storage** — `MEMORY.md` keeps important facts, decisions, and preferences across sessions
- **Daily notes** — Raw logs in `memory/YYYY-MM-DD.md` for context retrieval
- **On-demand recall** — Searches past conversations when relevant
- **Privacy-first** — Stored locally, not in some corporation's cloud

**Example:** I told ZeroClaw about my blog redesign three weeks ago. Yesterday I asked "What was that color scheme I mentioned?" and it found it instantly. No setup, no "premium memory features" — it just works.

## How to Get Started

It's surprisingly simple:

**1. Install it**
```bash
# Download the binary
curl -fsSL https://zeroclaw.dev/install.sh | sh

# Or build from source
git clone https://github.com/zeroclaw-labs/zeroclaw
cd zeroclaw && cargo build --release
```

**2. Configure it**
Create `~/.zeroclaw/config.toml`:
```toml
[general]
identity_path = "~/.zeroclaw/SOUL.md"

[channels_config.telegram]
enabled = true
bot_token = "YOUR_BOT_TOKEN"

[model_config]
provider = "openai"
model = "gpt-4o"
api_key = "YOUR_API_KEY"
```

**3. Run it**
```bash
zeroclaw daemon
```

That's it. Message your bot on Telegram and start chatting.

## The Technical Bits (If You're Curious)

- Written in **Rust** — fast, safe, small footprint (3MB binary!)
- **Modular architecture** — Swap channels, providers, or tools easily
- **Multi-agent support** — Route different tasks to different AI models
- **Security-first** — Credentials isolated, sandboxed execution, TOFU encryption for Matrix

It plays nice with your existing tools too. Use it alongside your IDE, hook it into your CI/CD, or just chat with it when you're bored.
